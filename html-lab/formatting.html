HTML Formatting

b tag is used to make text bold

strong tag is used to make text strong

i tag is used to make text italic

em tag is used to make text emphasized

u tag is used to make text underlined

mark tag is used to highlight text

small tag is used to make text small

del tag is used to strike through text

ins tag is used to insert text

sub tag is used to make text subscript

sup tag is used to make text superscript
